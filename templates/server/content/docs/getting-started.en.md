## 1. Sign in to the admin

Create the first administrator with the setup command from the project README, then open the admin console.

## 2. Make the site yours

- Update the site name, navigation and footer under **Site settings**.
- Edit the home page: publish a page with the slug `home`.
- Replace the placeholder Privacy, Terms and Refund pages.

## 3. Configure plans

Create plans and credit packs, then enable a payment provider to start selling.

## 4. Write content

Blog posts, docs and changelog entries can be written in the admin or added as files under `content/`.
