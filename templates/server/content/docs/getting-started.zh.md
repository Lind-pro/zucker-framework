## 1. 登录管理后台

使用项目 README 中的初始化命令创建第一个管理员，然后打开管理后台。

## 2. 定制网站

- 在 **站点设置** 中修改站点名称、导航和页脚。
- 编辑首页：发布一个 slug 为 `home` 的页面。
- 替换占位的隐私政策、服务条款和退款政策页面。

## 3. 配置套餐

创建套餐和积分包，然后启用支付服务商开始销售。

## 4. 撰写内容

博客文章、文档和更新日志可以在管理后台撰写，也可以以文件形式放在 `content/` 目录下。
