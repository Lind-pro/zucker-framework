# NestJS Server Template

基于 @zucker-framework/* 包的 NestJS 后端骨架。

## 功能
- 认证授权 (@zucker-framework/auth)
- CRUD 基础 (@zucker-framework/crud)
- 访问日志 (@zucker-framework/logging)
- 数据字典 (@zucker-framework/dictionary)
- 运行时配置 (@zucker-framework/config)
- 多通道通知 (@zucker-framework/notification)
- AI 集成 (@zucker-framework/ai)
- 文件存储 (@zucker-framework/storage)
